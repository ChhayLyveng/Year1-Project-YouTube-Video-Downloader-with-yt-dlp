# Rock Paper Scissors GUI

A classic Rock, Paper, Scissors game implemented with a graphical user interface (GUI) using Python's built-in Tkinter library.

## Features

- **Interactive GUI**: Simple, easy-to-use window with button controls.
- **Dynamic Logic**: Uses Python's random module to ensure the computer's moves are unpredictable.
- **Instant Feedback**: Displays the player's choice, the computer's choice, and the final result (Win/Loss/Tie) immediately on the screen.
- **Custom Styling**: Features a "Dark Green" theme with "Cooper Black" and "Comic Sans MS" fonts for a playful aesthetic.

## Requirements

- Python 
- Tkinter: Usually comes pre-installed with Python.

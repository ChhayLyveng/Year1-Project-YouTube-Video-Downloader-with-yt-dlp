# $A simple YouTube video downloader built with Python, yt-dlp, and FFmpeg.$

## $Requirements$

- Python 3.11
- Visual Studio Code
- FFmpeg
- yt-dlp

1. Install VS Code and Python

Download and install:

- Visual Studio Code
- Python 3.11

Make sure Python is added to PATH during installation.

2. Install yt-dlp

Open Terminal (or Command Prompt) and run:

```bash
pip install yt-dlp
```

3. Install FFmpeg

3.1 Download FFmpeg
```python

```
3.2 ffmpeg-2024-08-21-git-9d15fe77e3-full_build.zip
